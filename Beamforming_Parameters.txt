Parameter	Object	Range / Values	Default	Description

mMIMOAntArrayMode	NRCELL	0 to 7 (various antenna array splits)	-	Defines allocation of active antenna TRX to cell (e.g., full 64TRX, left/right 32TRX, etc.)

NRCELL.beampoweroffsetthreshold	NRCELL	0 to 15 dB (step 1 dB)	6 dB	Limits the upper level of power balancing offset
NRCELL.numDftBeamMuteRight	NRCELL	0 to N (number of beams muted on right side)	0	Number of rightmost DFT beams muted in horizontal plane
NRCELL.numDftBeamMuteLeft	NRCELL	0 to N (number of beams muted on left side)	0	Number of leftmost DFT beams muted in horizontal plane
dlMimoMode	NRCELL	30 (2x2 Closed Loop), 40 (4x4 Closed Loop), 50 (2x2 Open Loop), 60 (4x4 Open Loop), 70 (8x4 Closed Loop)	30 (2x2 Closed Loop)	Defines MIMO mode and beamforming type
